# Materiais até o 2º turno 2026

Cards, bom dia, cortes, lambes e impressos feitos com código a partir de dados públicos e falas registradas, sem IA generativa de imagem ou voz, sem rosto de candidato. Toda afirmação tem fonte e data na própria peça.

Abra `index.html` (ou a página publicada) para ver e baixar por família, público e canal. As regras para quem distribuir estão no topo da página: assine, nada pago, impresso com CPF e tiragem, não editar as peças de fato.
